# HSP予測システム（RDKit + LightGBM + Optuna）

## 概要

このプログラムは、SMILESで表現された分子構造から、ハンセン溶解度パラメータ（Hansen Solubility Parameters: HSP）の次の3成分を予測するPythonアプリケーションです。

- `δD`：分散力成分
- `δP`：極性成分
- `δH`：水素結合成分

RDKitで分子構造から特徴量を抽出し、LightGBMの回帰モデルで各成分を個別に予測します。Optunaによるハイパーパラメータ最適化、交差検証、分子骨格に基づく評価、ログ出力、学習済みモデルの保存・再利用に対応しています。

> **注意:** このプログラムの評価機能はモデルの性能を測るためのものであり、予測精度や実験結果との一致を保証するものではありません。実務・研究で利用する前に、データの品質と評価結果を確認してください。

## 主な機能

- SMILESの検証と、RDKitによる分子構造の解析
- 官能基数、環構造に関するパターン、分子量、TPSA、HBD、HBA、LogP、sp3炭素比率、Hall–Kier alphaなどの特徴量抽出
- `δD`、`δP`、`δH` の3モデルを個別に学習
- 学習済みモデルを `models_lgbm` フォルダーに保存し、条件が一致する場合に再利用
- 学習データ・特徴量定義のフィンガープリントによるモデル再利用判定
- Optunaによるハイパーパラメータ最適化
- ランダムK-fold交差検証
- Bemis–Murcko骨格を用いた構造ベースのGroupKFold評価
- MAE、MSE、R²の表示
- コンソールと `hsp_execution.log` へのログ出力
- 任意のSMILESを指定した予測
- `δD`、`δP`、`δH` からの合成値 `δT` の計算

## 動作環境

Python 3.10以降を推奨します。RDKit、LightGBMなどの対応バージョンは利用環境に依存します。

## ファイル構成

同じフォルダーに、次のファイルを配置してください。

```text
HSP_project/
├─ hsp.py                    # 本プログラム
├─ HSP_data_p.csv           # 学習用CSVデータ(参考)
├─ hsp_execution.log         # 実行時に自動作成
└─ models_lgbm/               # 学習済みモデルを自動保存
```

スクリプトは実行時のカレントディレクトリではなく、**スクリプト自身が置かれたフォルダー**を基準にCSVとモデルフォルダーを参照します。

## 学習データ（CSV）の形式

`HSP_data_p.csv` に、少なくとも次の列を用意してください。

| 列名 | 内容 |
|---|---|
| `SMILES` | 化合物のSMILES表記 |
| `δD` | δDの実測値 |
| `δP` | δPの実測値 |
| `δH` | δHの実測値 |
| `化合物名` | 任意。指定すると学習データの予測一覧に化合物名を表示 |

CSVはカンマ区切りで保存(UTF-8)してください。SMILESが空欄、またはRDKitで解析できない場合はエラーになります。

## インストール（Windows CMD）

コマンドプロンプト（CMD）でプロジェクトフォルダーに移動し、必要なパッケージをインストールします。

```cmd
python -m pip install pandas numpy joblib optuna lightgbm scikit-learn rdkit
```

Python環境やRDKitの配布状況によってインストールに失敗する場合は、RDKit公式ドキュメントの推奨インストール方法を確認してください。仮想環境を利用すると、他のプロジェクトとの依存関係の衝突を避けやすくなります。

## 実行方法（Windows CMD）

以下は、ファイル名を `hsp.py` にした場合の例です。

### 1. 通常実行

```cmd
python hsp.py
```

保存済みモデルがデータ・特徴量定義・モデルバージョンと一致すればロードし、一致しなければ学習し直します。学習データに対する参考予測を表示し、既定のテストSMILESも予測します。

### 2. 学習済みモデルを無視して再学習

```cmd
python hsp.py --retrain
```

### 3. Optunaでハイパーパラメータを最適化して学習

```cmd
python hsp.py --tune
```

各目的変数についてOptunaの探索を行ってから、全学習データでモデルを学習し、保存します。探索には時間がかかる場合があります。

### 4. 交差検証と構造ベース評価

```cmd
python hsp.py --evaluate
```

ランダムK-fold交差検証とBemis–Murcko骨格による構造ベース交差検証を実行します。評価後、通常のモデルロード／学習処理と既定の予測も続けて実行されます。

### 5. ランダムK-fold交差検証のみ

```cmd
python hsp.py --cv
```

### 6. 構造ベース交差検証のみ

```cmd
python hsp.py --structure-evaluate
```

### 7. SMILESを指定して予測

```cmd
python hsp.py --smiles "CC(O)C"
```

複数の分子を一度に指定する場合は、`--smiles` を複数回記述します。

```cmd
python hsp.py --smiles "CC(O)C" --smiles "C1COCOC1"
```

## 評価方法について

### ランダムK-fold交差検証

データを複数のfoldに分割し、各回で一部を評価用、残りを学習用にします。各foldのMAE・MSE・R²と、fold間の平均値・標準偏差を出力します。データ分割による性能のばらつきを把握するための評価です。

### 構造ベース交差検証

RDKitのBemis–Murcko骨格をグループとして `GroupKFold` で分割し、同じ骨格グループが学習側と評価側に同時に入らないようにします。異なる骨格の化合物に対する予測性能を、ランダム分割とは別の観点から確認できます。

この実装では、Bemis–Murcko骨格が空になる非環式分子について、正規化SMILESごとにグループ化します。そのため、異なる非環式分子同士の類似性まで分離できるわけではありません。構造ベース評価の結果は、骨格の種類数と各グループのデータ件数を考慮して解釈してください。

### 指標の意味

- **MAE**：予測値と実測値の絶対誤差の平均。小さいほど誤差が小さいことを示します。
- **MSE**：誤差を二乗して平均した値。大きな誤差をより強く反映します。
- **R²**：実測値のばらつきに対するモデルの説明力を表す指標です。評価データが少ない場合は不安定になり、負の値になることもあります。

学習データ全体に対する指標は学習時に使ったデータでの評価なので、未知データに対する性能と同じではありません。未知化合物への性能を判断する際は、交差検証や構造ベース評価を優先して確認してください。

## 出力ファイル

| ファイル／フォルダー | 内容 |
|---|---|
| `models_lgbm/HSP_LGBM_δD.joblib` | δDモデルと管理情報 |
| `models_lgbm/HSP_LGBM_δP.joblib` | δPモデルと管理情報 |
| `models_lgbm/HSP_LGBM_δH.joblib` | δHモデルと管理情報 |
| `hsp_execution.log` | 実行ログ、評価結果、警告・エラー |

モデルファイルはPythonの `joblib` で保存されます。信頼できない提供元のjoblibファイルをロードしないでください。

## 注意事項・既知の制約

- 予測値の `δD`、`δP`、`δH` は、出力時に負の値を0に補正します。補正後の値が物理的に妥当であることを保証するものではありません。
- `δT` はコード内で `sqrt(δD² + δP² + δH²)` として計算する派生値です。
- `--evaluate` はランダムK-foldと構造ベース交差検証を実行します。コード内のランダム・ホールドアウト関数は、このオプションからは呼び出されていません。
- Optunaの探索時に使う交差検証はランダムK-foldです。構造ベースの交差検証でハイパーパラメータを最適化する実装ではありません。
- 同じデータで特徴量やパラメータを何度も調整すると、評価結果が楽観的になることがあります。最終評価には、調整に使っていない独立データを用意するのが望ましいです。
- SMARTSによる官能基カウントはパターンへの一致数です。特に環サイズやアセタールに関するカウントが化学的に意図した定義になっているかは、代表的な化合物で確認してください。
- 実測HSP値の品質、単位、出典、化合物の重複・塩・異性体の扱いが、モデル性能に大きく影響します。
